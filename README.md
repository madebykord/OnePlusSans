# One Sans

One Sans font from OxygenOS 16 aka OPPO Sans 4.0

# Configuration

I recomend using [fonttools](https://github.com/fonttools/fonttools) varLib.mutator via [Python](https://python.org) if you want to change the variable font to a static one.

Usage: 

'fonttools varLib.mutator "variable font directory" wght=N ital=N'

Read [fonttools](https://github.com/fonttools/fonttools) documentation for more information.

You can also just use already configurated static fonts in the [static](https://github.com/wlpne/OneSans/blob/main/static/) folder of the repository.

## wght=N - Weight of the font

**Where N is a number from 0 to 1000**

Regular - 400

Medium - 500

Semi-Bold - 600

Bold - 700

Extra Bold - 800

Black - 900

## ital=N - Represents if the font is *Italic* or not

**Where N is 0 or 1 (False or True)**

False - 0

True - 1
