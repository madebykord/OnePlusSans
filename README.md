# One Sans

One Sans font from OxygenOS 16 aka OPPO Sans 4.0

# Configuration

I recomend using [fonttools](https://github.com/fonttools/fonttools) via [Python](https://python.org) if you want to change the variable font to a static one, or you can use already configurated static fonts in the [static](https://github.com/wlpne/OneSans/blob/main/static/) folder of the repository.
